Rising Roots
Full-Stack Trading SaaS Platform - Technical Specification
Version 2.0.0 Production Documentation

1. System Architecture Overview

Rising Roots is a production-ready, monorepo trading community management SaaS built for stock, crypto, options, and futures trading groups.

  • Frontend: React 19, Vite 8, Tailwind CSS, React Router v7.
  • Backend API: Node.js v24, Express, Cors, Dotenv.
  • Database & Persistence: MongoDB Atlas / Mongoose v9.10 (Fully async document-based schema).
  • Security & RBAC: Password encryption via bcryptjs (10 rounds), session security via signed JSON Web Tokens (JWT).
  • Intelligence & Analytics: AI Trade Evaluator, Pattern Insight Detector, and AI Copilot Chat Engine.
  • Monetization & Expiry: Automated daily subscription expiry task and Razorpay payment gateway integration.

5. Master API Specifications

POST  /api/auth/register          -> Register user & issue JWT
POST  /api/auth/login             -> Authenticate credentials & issue JWT
GET   /api/auth/me                -> Fetch current authenticated user
GET   /api/trades                 -> Query trade journal entries (filter by status, asset, symbol)
POST  /api/trades                 -> Log new trade execution
PATCH /api/trades/:id/close       -> Quick-close open trade with exit price
DELETE /api/trades/:id            -> Delete trade log entry
GET   /api/trades/stats           -> Trade performance metrics summary
GET   /api/portfolio/me           -> Personal open exposure & asset allocation
GET   /api/portfolio/community    -> Group net metrics & ranked trader leaderboard
POST  /api/ai/analyze             -> AI Risk Evaluator & Strategy Grade
GET   /api/ai/insights            -> AI-detected trading habits & pattern warnings
POST  /api/ai/chat                -> AI Copilot Assistant Chat
GET   /api/subscriptions/expiring -> Fetch members expiring within N days
POST  /api/subscriptions/renew/:id -> 1-Click renew member subscription (+N days)
POST  /api/payments/create-order  -> Generate Razorpay checkout order payload
POST  /api/payments/verify-payment -> Verify payment signature & auto-renew access
POST  /api/payments/webhook       -> Process Razorpay/Stripe event payloads
GET   /api/members                -> Search & filter community members list
POST  /api/members                -> Add new community subscriber
PATCH /api/members/:id/toggle     -> Toggle member access status

6. Installation & Execution Guide

Run the commands below in your terminal:

# 1. Seed MongoDB Database (Admin account & sample data)
cd backend
npm run seed

# 2. Start Backend API Server
npm run dev

# 3. Start Frontend Client (In a second terminal)
cd ../frontend
npm run dev
